# 深海灯塔：第三阶段——材质与基础光照 v1

日期：2026-10-21。基于用户已验收的 EastCoast-Blockout-3-Natural 白模继续制作。

## 本轮范围

为已验收地形添加统一的岩石、湿润岸脚、浅海沙底、木材、灯塔和角色材质；建立暖日光、冷环境光与青绿浅海／蓝色深水的基础关系。岩面使用世界坐标三向投射，船体使用局部坐标映射，避免运动时纹理滑动。复用原工程已有贴图及许可，不另行下载素材。

原版 V2 和白模验收版仍保留各自的可运行文件。第三阶段构建已有 CoastBlockout.unity，运行时挂载材质层；不重新生成、保存白模场景或修改网格、碰撞体、航道及参考相机。

这是一轮材质与光照基础制作。它还没有达到目标图的完整美术效果：植被、珊瑚、多种鱼群、精细船屋道具，以及浪花、折射、反射、焦散等水体细节仍需后续制作。目标图是风格与构图参照，evidence 中的图才是本轮 Unity 独立播放器的真实截图。

## 源码包

`Files/Runtime`：材质运行层、会话接入、实机验证代码。

`Files/Editor`：独立构建入口 `Deepsea.Editor.CoastMaterialsBuild.Build`。

`Files/Shaders`：岩岸／地面／木材基础着色器与深度水面着色器。

`baseline`：第三阶段开始前两份运行脚本，用于追踪本轮接入改动。

依赖：现有 Unity 2022.3.62f3c1 工程、URP 14.0.12、已验收白模资源与原工程的 CoastSlice 贴图。本包是该工程的增量源码与证据，不是独立完整 Unity 工程。

在关闭 Unity Editor 后运行 `Install-CoastMaterials.ps1`。脚本先备份被替换的两份运行脚本，再安装 Files 下内容。然后运行 `Build-CoastMaterials.ps1`，它只调用第三阶段构建方法，并运行完整实机检查。不要用旧 CoastBlockoutBuild.Build 构建此阶段，以免重建已验收白模。

`-coast-materials -whitebox-check` 为完整实机验证：渲染、固定参考机位的解除限帧采样、原船控制器、步行、上下船和鱼群洞口碰撞采样。

`-coast-materials -whitebox-visual` 仅复查渲染，不验证控制器。`water-depth.png` 是诊断图，红色亮度表示透明水面从相机深度纹理采样到的水下厚度，不是成品画面。

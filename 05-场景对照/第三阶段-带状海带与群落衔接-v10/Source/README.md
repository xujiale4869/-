# 深海灯塔 · 带状海带与群落衔接 v10

基于已验证 v9 的 Unity 2022.3 / URP 14 源码补丁。绿色叶面继续沿用用户认可的版本；本轮重点调整三维植物形态、群落分布和根部接地。不是目标参考图美术全部完成的结论。

## 本轮改动

- 新增实际导入 Unity 的 `KelpRibbon.obj` 模型：518 顶点、690 三角形、6 条带状叶片。每片长度与宽度之比约 13.6–24.5，替换原先像陆地灌木的短宽侧叶。保留 UV、平滑法线、短小固着根，统一水流朝向，略作实例角度变化。
- 编辑器将 OBJ 转成专用资源网格，并把顶点、UV、索引和摆动权重写入独立数据资源，避免运行时读取被打包裁剪的导入网格属性。按真实高度设置根部到叶尖的摆动权重。没有添加碰撞体。
- 海草叶片变细、拉长，同时保留足够密度。继续使用干净绿色贴图，不使用弃用的褐色斑驳稿。
- 群落由圆形随机盆栽改为沿礁台伸展的长条状分布，通过覆盖噪声和边缘稀疏控制留下空隙。珊瑚、海草、长海带形成不同高度。
- 在放置高植物前生成既有鱼群路线；靠近路线的植物限制最高点，为游动空间留出高度。船泊位与贯通岩洞附近继续保留原通行区域。
- 根部沿真实碰撞表面贴合，并埋入约 4.5cm；固着根贴合岩面，叶片逐渐转向上方。无法满足接地范围的生长点不放置长海带，改用占地更小的海草，并记录拒绝数量。新增检查读取新模型实际最低顶点，检查它与海床的间距；同时检查全体水下植物最高点没有露出水面。
- 岩岸沿用 v9 的重叠岩层，本轮继续拍摄同机位近景复查接缝。地形与原碰撞不在本轮重建。

## 安装与验证

基于已验证 v9，关闭 Unity 编辑器后运行 `Install-CoastArtV10.ps1`，再运行 `Build-CoastArt.ps1` 和 `Verify-Final.ps1`。安装前检查源文件哈希，备份受影响源码和资源。不要调用 `CoastBlockoutBuild.Build`。

构建入口：`Deepsea.Editor.CoastMaterialsBuild.Build`。

输出：`Builds/CoastArtV10/GuichaoBay-ArtV10.exe`。

正常游玩参数：`-coast-materials -coast-ecology -screen-fullscreen 0 -screen-width 1920 -screen-height 1080`。

验证包括 Unity 导入与着色器支持、模型预算、根部接地、海草水线、原航行和 12 个步行点、上下船、鱼群穿洞，以及 334 个受保护文件。性能使用原生 1920×1080、renderScale=1、固定参考镜头、1200 帧无上限采样；正常游玩仍限制 60 帧。大窗口仍保持约 1080p 的三维像素预算。

WASD 航行/步行，F 上下船；F2 生态，F3 岸上草地，F4 白模，F6 参考镜头，F7 岩洞，F8 岸壁收边，F9 水面。

## 本次实测

- 原生 1920×1080、renderScale=1、1200 帧固定机位采样：平均 88.41 FPS，P95 16.16ms，P99 20.09ms。正常游玩限制为 60 帧，此数值不代表全地图最低帧率。
- 80 丛带状海带、237 丛海草、62 处珊瑚；水下植被与珊瑚共 193060 三角形。单个海带模型 690 三角形。
- 80 丛海带全部完成模型根部检查；最低顶点到海床的最大正间距约 9.57cm，最大埋入约 19.68cm；6 个无法满足接地范围的候选点改用海草。最高水下植物顶点仍低于水面。
- 原航行、12 个步行点、上下船、鱼体穿洞 3520 次采样和生态路线 14080 次采样通过，334 个受保护文件全部未变。
- 本轮实机仍有珊瑚块状感和岩岸接缝，需要继续整理；不作为目标参考图美术完成的结论。

## 模型与贴图来源

`Assets/KelpRibbon.obj` 为本轮制作的实际模型源文件，构建脚本为 `Tools/Build-Kelp-Asset.py`。`Assets/kelp-mesh-audit.json` 记录模型顶点、面数、包围盒、UV、最小三角形面积与各叶片长宽比。模型数据检查不代替 Unity 实机验收。

绿色叶面沿用 v9 内置 ImageGen 生成素材，来源与提示词见 `Assets/source-record.json`；其余模型、扫描纹理和许可记录沿用 v9。模型源文件及素材会安装到既有工程，本包不包含第三方原始大型资源。

## 仍需继续处理

群落疏密、植物轮廓、岩岸局部接缝与整体光照仍需继续按实机整理。本包中的截图如有，均为本轮 Unity 播放器实际渲染；模型与贴图预览不作为实机效果图。

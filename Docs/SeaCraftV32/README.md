## 这次改了什么

- 三座房屋和独立船坞滑道使用四个 Blender 模型，共 91860 个三角面。酒馆能看到错缝叠瓦、斜搭木墙、梁柱和石基。窗、金属和屋顶仍有各自材质槽。
- 前院、岸边通道、海洋小馆门廊和可建造栈桥按实际宽度分板。先生成板缝和倒角，再合并同材质部件。原主码头沿用网格和碰撞体，木材组接入新着色器。
- 木、石、板岩的程序化微浮雕、顶点遮蔽和潮间带湿色由 `StylizedCoastalCraftV32` 提供。保留 v30 的界面和 v31.1 的水面、珊瑚及存档路径。

## 实机验收

- Unity 构建成功，报告记录 24 项构建警告。独立程序通过 174 项运行检查和 20 项 Windows 原生键鼠检查。
- 三张图均取自同一版独立程序的 1920×1080 可见窗口。普通启动读入 19 个既有建造设施，玩家存档记录 1 个已建展缸。隔离测试前后核对 5 份正常 JSON 存档。
- 本轮验收覆盖新版木石、沿用界面、已有航行/建造/展室流程与 v31.1 珊瑚。整体画风仍待游玩反馈。

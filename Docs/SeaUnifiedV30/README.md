# v30《雾岬岛·东岸》：一体半岛与斜切海洋 UI

用户交接包已接入 Unity2022.3 URP14。新场景 `CoastSeaUnifiedV30.unity`，独立程序 `Builds/SeaUnifiedV30/Guichao-SeaUnifiedV30.exe`。桌面最新版指向新程序；v29 二进制保留。用户指定的三份核心文件在原 SeaSeamlessWorldV29 目录升级，新功能按 partial 文件补齐，原始包完整保存在 `Tools/SeaUnifiedV30/OriginalInputs/`。

## 本轮变化

- 新岛屿/大陆架只有一张 350×340m 连续网格，73,341顶点，逐顶点写入沙/草覆盖度。海拔0.45m以下保持纯沙；高度、内陆距离与有机噪声共同控制斑驳过渡。旧地形与海岸只做运行时克隆，不改原网格和贴图。实际残留的大沙块来自六张 `EN_MapleSubstrate` 旧条带，已与 FineShore、Land_Rock、内陆/岬角/树根地形一起使用共同生态过渡；不把全部问题归咎于原稿声称的两个新网格材质不同。
- 北、南陆地抬升为完整丘陵与红枫林，18棵新增红枫使用工程原有树干与带透明裁切的红叶材质。新增46岸岩、56外海礁、52珊瑚组、42绿色海草组；植物按真实可见碰撞表面落根并限制顶端高度。原船、角色、海草与岩石贴图继续复用。
- 海面520×520m；大陆坡采用58m余弦沉降，所有四边界与背景底面统一到海平面下14m，避免边框本身形成高度阶跃。原内湾真实采样区保守下包络保留，以保护精修岸岩；因此局部旧礁壁仍有地形层次，不声称全地图百分百无台阶。
- 普通新建网格与放置同时限制水深0.45–3.2m，四个相邻2m采样高差不超过0.65m，另保留原五点地基、碰撞与资源检查。新存档继承四块起始码头接头，避免收紧条件切断登岸步道；这是起始旧设施，不是任意深水建造入口。旧布局仍直接迁移，不自动删除老设施。
- Persona 灵感体现在斜切切面、青色错位背板、金色选中态、斜向细纹、大号水印键与紧凑图标；选中卡片有抬升、放大，工具另有轻微倾斜。七图标128px源纹理、实际42参考像素，一次烘焙并复用；没有逐帧创建纹理。资源栏把潮汐石和珊瑚苗分开，黄铜保留在建材库存。钓鱼反馈、鱼箱、暂停、展缸仍使用实际交互。

## 操作与进度

航行 WASD，滚轮远眺；B/G进入海湾营造，1–4选设施，R旋转，左建右拆，G/B返回。L控制船尾灯，1钓竿、2挂钩，鱼影旁E钓鱼，Tab鱼箱，F上下船，Esc暂停。

展室：B布置、V观赏已建展缸、F返回码头。空建设位不能近景观赏，界面提示先建展缸。A/B/C选择与地面标记对应，活动目标用金色和菱形表示；普通目标用青色。

正常收藏/产品名保持v21。v30独立建造档 `sea-bay-expansion-v30.json` 首次复制 v29 布局，旧 v29 文件不改。测试在加载前隔离玩家和布局存档，原生V测试先在隔离档建好实际免费首缸，避免把空缸前置条件误判成按键失效。

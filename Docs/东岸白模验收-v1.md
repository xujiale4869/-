# 东岸白模验收 v1
日期：2026-10-21。目标图：Docs/CoastBlockout-References/Reference-Stage2.png。
当前交付：在原Unity工程内建立独立、可操作的白模场景，按目标图落实岩岸、灯塔、码头、小船、浅湾、礁台和深沟的主要空间关系。局部岩体轮廓仍可继续对照细化。

## 体验
桌面入口：深海灯塔－白模验收版.lnk
程序：Builds/CoastBlockoutV1/GuichaoBay-Blockout.exe
WASD航行/步行；低速接近栈桥按F下船，返回登陆点按F登船；滚轮缩放。
F5切换弱透视/正交；F6切换参考/跟随镜头；F8帧率；F9隐藏水面；F10隐藏界面；Home回到起点；Esc暂停。
交互版限60帧。白模入口不写入正常游戏进度。

## 原工程与共用资源
独立场景：Assets/Deepsea/Scenes/CoastBlockout.unity。
共用地形Prefab：Assets/Deepsea/Resources/CoastBlockout/EastCoast.prefab。
共用布局与海底数据：Assets/Deepsea/Scripts/Runtime/CoastBlockoutLayout.cs。
不规则岩体由CoastBlockoutRock的同一组三角形生成显示网格、MeshCollider和海底高度查询；技术水面直接读取真实场景深度。
保留原BoatController、ExplorerController、ExpeditionController进行实际操作，原东岸水平坐标仍为泊位(53,94)、登陆点(46,94)。
原场景GuichaoBay.unity与原V2程序均已对照接入前SHA256，内容一致。原桌面制作版入口继续指向V2。
接入前备份：Tools/CoastBlockout/Before-20261021-091538。

## 结构内容
四块连续地形网格，共74992个地形三角形；185个大小岩体，包含岸壁、碎岩、礁台侧壁和前景岩台。
灯塔与小船用于白模比例；码头桥面、梁、落底立柱、灯塔步道与石阶均有实际几何。
全部实体使用同一灰色材质；水面仅显示透明灰蓝色技术色，不包含成品水体光学。
白模场景用于结构与通行验收；原任务和完整生态仍保留在原制作版。

## Blender → Unity 的实际作用

v19 也已使用 Blender，工具切换本身不会带来质量提升。其两处旧岸岩主要来自模板的拉伸、旋转、体素化与减面，本轮改成明确设计的岩层边界、断裂块、斜面和磨损边缘，保留可继续编辑的高低模。它让轮廓、树根承托和接缝有独立可编辑的形体。

局部岩段高模 **397472** 三角面，LOD0 **6656**、LOD1 **3992** 三角面。高模中的厘米级起伏和细节投射为切线法线；底色、粗糙度也按匹配高低模烘焙。AO 改为隔离低模的几何烘焙，避免重叠高低模互相遮蔽。四张源图均2048×2048，底色为sRGB，其余为线性数据。底色复用 v19 原图经投射，不声称物理扫描或本轮重新生成原生纹理。

Unity 使用唯一UV、法线、AO和粗糙度，分别控制表面起伏、岩缝环境遮蔽和水线干湿反射。低模承担大形，高模细节由贴图承担，避免把全部高模面数投入运行时。粗糙度随高度过渡，金属度为0。它仍不能代替对实际游戏镜头的美术判断。

新岩台抬高了原树的承托面，Tree00 非根树干与冠叶整体上移 **1.6267566m**，重建7条根并采样岩面贴合，其他7棵树未变。落叶源锚点仅同步高度，未向外移动；21处触水目标保留。

## 水面碎光

原太阳与镜头的方向组合几乎不可能由原平缓波纹反射到太阳。新增独立 `Deepsea/CoastSunGlintStudy`，以稀疏动态微面元反射实际主光，保留原水色、吸收、折射和低频波纹。克隆原 Water.mat 以保存实际浅水/深水颜色和RippleSlopes，原水材质与原核心文件未修改，折射仍为 `.0022`。

第一次实机闪点过少；最终使用指数160，Intensity2.4 / Scale8 / Roughness.52 / Density.9 / Coverage.25 / Speed.6。Inspector默认值与范围已同步。原始太阳glint保留，新增部分可单独关闭，未改全局太阳或曝光。它是可控美术近似，不能当作完整无偏海面光传输。水底焦散与水面反射仍是两个系统。

最终实机截图的远侧水域裁片约98.91%像素变化小于.02，新增亮点清楚可见。该比例受蓝噪声SSAO影响，仅辅助检查水域是否整体变白，不是审美评分或严格能量测量。离线研究和源码差异在 `water-study/`。

## 实际验证及范围

原生1920×1080、renderScale1、Intel Arc130T，岸边镜头新增碎光开启1200帧平均 **65.4819 FPS**，P95 **16.6558ms**；关闭后另一1200帧窗口 **66.0107 FPS**，P95 **16.6347ms**。两个顺序时间窗的船、鱼和叶片相位不同，差值不能当作精确shader耗时。不能与旧全景采样或旧版本帧率直接推导质量结论。

实机截图无黑帧、粉色或记录到的运行错误；原生1080p近景、岸边、全景、另一视角和水下视角已查看。最终开启碎光片段含缓慢下落、触水与漂浮红叶。运行时12600次落叶状态检查通过；另外7230次新岩体上方空气路径检查通过，最低垂直余量约.1446m；4200次水面漂流足迹与28480次鱼群路线检查通过。空气路径检查针对新岩段，不宣称已解决全世界所有旧树枝碰撞。

局部岩段模型验证0失败，**1项提示：3个顶点间距小于0.1mm**；封口及流形检查通过，UV在0–1。Tree00两网格验证0失败0提示。GLB回读6656面、0错误，嵌入底色、法线及合并AO/粗糙度三张图。GLB查看档整体抬高1.1088836m，原blend与Unity JSON没有偏移；完整水、灯光及其余场景精确状态以Unity为准。

184项旧脚本/着色器/水材质/v19场景哈希保持一致，v19冻结14输入保持一致。场景只读检查121个旧对象、107项网格、113材质槽、21触水目标及其余7个锚点，除明确授权的替换项外保持一致。QualitySettings、ProjectSettings逐字节恢复；GraphicsSettings只保留2个新增shader引用。证据在 `review/file-preservation.json`、`review/preservation-audit.json` 及对应diff。

## 继续编辑与重建

`EN_FineShore_master.blend` 保留本轮岩段高低模，`EN_FineShore_baked.blend` 保留烘焙材质与两个LOD；`EN_FineShore_tree-contact.blend` 保留树根与原红枫环境的局部上下文。源blend中未替换的原岩隐藏，Unity删除的只有指定两处旧岩。

工具入口：工程 `Tools/CoastArtV20/Rebuild-FineShore.ps1`。默认校验并恢复11项冻结输入，`-Build` 构建。新生成或重新烘焙属于新稿，需要再次验收，不承诺跨环境逐字节生成相同网格。制作脚本在本目录 `build/`，冻结资产不依赖再次生成。

## 尚存差距

新岩段已能独立比较层次和承托，但部分直线断缝与大块平面仍有拼装感；与概念图中的自然破碎、细小侵蚀、沙隙和细腻反射仍有距离。其余旧岩、木阶、树枝和整体光照尚未本轮重做。新增碎光比原型更明显，仍需要用户动态观看后决定强度与方向。用户尚未评价或认可v20，不能把本次检查通过写成匹配原图或整景质变。

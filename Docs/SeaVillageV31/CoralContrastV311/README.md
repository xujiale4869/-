# 深海灯塔 v31.1 珊瑚与海葵辨识度

桌珊瑚和海葵使用专属材质。桌珊瑚用暖橙色盘和冷青盘沿区分各层，海葵用粉紫主体和浅色触手尖端区分冠部与礁石。新增参数默认关闭，其他植物延续原有着色。v30 界面继续使用。

航行近景与远景实际视场角约 9.4° 和 36.2°。抽查实际群落后，选用桌珊瑚 10 号和海葵 9 号作为航行样本。海葵的成对特写取自第二次构建的 12 号样本，根部水深约 1.92 米，避免船身遮挡。第三次构建只补了正式启动修复，表内航行照及桌珊瑚特写来自第三次构建。[9 号海葵在礁缘的特写](anemone-reef-detail.jpg)用于主图。其他四类水下形态分别见 [鳗草](14-flora-0.jpg)、[公牛藻](14-flora-1.jpg)、[海扇](14-flora-2.jpg) 和 [管状海绵](14-flora-3.jpg)。

同镜头下，桌珊瑚由接近水色的青绿色转为暖橙色，放宽后更容易分出两层盘。海葵在浅水近景里可通过粉色触手辨认，约 1.92 米的特写更偏冷白。最远航行镜头仍主要看得到色点，礁石和船身仍可遮住轮廓。辨识改善以这几处实拍为限，整体美术状态仍为初稿。

## 修改与验证

- 按真实物种索引处理 14 丛桌珊瑚、13 丛海葵，其中 6 丛在草甸子节点中。桌珊瑚水平拟扩大 25%，海葵高度拟增加 22%。2 丛因水下空间受限而部分缩减增量，增强后最高顶点仍在水面下至少 0.33 米。
- Unity Windows 构建通过，构建报告记录 1 项警告。原生可见窗口通过 161 项运行检查和 20 项 Windows 键鼠检查。[运行检查](runtime-result.json) · [原生键鼠](native-result.json) · [物种统计和取景参数](coral-contrast.json)
- 隔离测试保持 7 份正常存档的哈希不变，原 v31 程序保留。普通启动验收发现已有展缸时，隐藏房间中的文字组件在初始化渲染器前设置字体会报错。调整初始化顺序后，使用含 1 座已建展缸的原存档通过普通启动，读取既有布局的 19 座设施。[普通启动验证](normal-startup.json)
- 首轮海葵取景受礁石遮挡。保留该轮原始记录在本机 Verification，随后抽查实际群落，选取可见样本补拍。院落与岸坎衔接及望远镜辨识仍是 v31 美术复核记录中的待办。

桌面「深海灯塔—最新版」打开 v31.1。单独的 v31.1 程序使用 v31 场景及正常存档路径。重建入口为 `Tools/SeaVillageV311/Rebuild-CoralContrast.ps1 -Build`，执行前会核对本次冻结的构建输入。需要精确重建原 v31 时使用提交 `426943b`。

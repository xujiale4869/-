# Local extension contract

Unity desktop ocean exploration/fishing/building prototype at native 1920x1080, with a 1280x720 planning UI regression view. Preserve the existing red-maple limestone coast, clean green kelp, turquoise/deep-water hierarchy, captain/boat and nautical Chinese interface.

Extend empty land with three occupational landmarks: boatwright workshop with boat repair activity/wood structures at the coast, L-shaped tavern/trading house, and an octagonal scholar lookout with telescope/deck. Add reeds/shore grass, driftwood and wet stones as the land/water transition. Show six distinguishable submerged morphologies: spiral eelgrass, bladder kelp, branching fan coral, hollow pipe sponge, layered table coral, tentacled anemone. Do not require new NPC AI, interiors, economy or new landing points.

Hard local visual checks: houses actually sit in terrain rather than cut through it or float; occupations read in the provided views; repair platform is visible and spatially plausible; vegetation does not obscure required structures; six new morphologies are visually evidenced rather than inferred from filenames; coast transition is legible; retained interface remains readable. Existing terrain seams are not automatically excused if they invalidate new integration.

Broader complete UI state comparisons, populated inventory, character expressions and independent unseen-content transfer are not supplied; global style remains provisional.

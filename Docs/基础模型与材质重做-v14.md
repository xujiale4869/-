# v14：先重做基础模型与材质

2026-10-24。本轮先恢复用户认可的 v12 水面，再重做灯塔和礁壁基础，停止增加珊瑚。原玩法、物理地形、碰撞网格与存档相关代码保留。

## 这次实际改了什么

水面核心着色器已逐字节恢复到 v12，折射恢复为 0.0022。新海床不再覆盖整片浅滩；新旧海床共用同一套沙、石材质计算，避免用两套底色把水染成不同颜色。覆盖边缘留下保守重叠带，修复点采样遮罩造成的细缝。新礁面改变水深，且水下阴影有适量散射补光，因此不宣称整张画面与 v12 像素一致。

灯塔采用重新制作的整体模型：塔身从底部到顶部收分；门窗有真实切口、凹进和石质窗套；灯室有独立窗玻璃、支架、平台和屋顶。灰泥与石材使用原有 2K 颜色、法线、粗糙度贴图和明确 UV。运行时 19320 面、8 个材质组、0 个新增碰撞体。旧模型只在白模对照时显示。

礁壁改为分层截面与不规则裂隙，并保留几何折角；8 块共 36292 面。原地形只调整渲染法线，碰撞仍使用原网格。木板改为沿板向的 UV，使用统一的表面材质计算。

没有增加珊瑚种类或投放尝试次数。群落按新可见表面重新落点，实际珊瑚 511 丛（上限仍为 512）；绿色海带重采样后为 108 丛。数量不是本轮美术验收标准。

## 已完成的检查

独立程序检查通过，失败列表为空。原生 1920×1080、渲染比例 1.0，1200 帧固定镜头样本平均 **76.28 FPS**，P95 **14.66 ms**，P99 **15.49 ms**。这是一次固定场景样本，不代表全地图长期表现。

原船控制器实航 15.70m；上下船、12 个步行检查点与穿洞通过。实际可见礁面鱼群检查 31360 次，碰撞 0 次。路线查询改为直接对烘焙网格的两个三角面插值，避免连续高度公式漏掉锐利台阶。其余 77 个既有运行时源码文件哈希不变；原地形布局、地形构造、船控制器与游戏主逻辑源码已单独核对。

灯塔交付网格检查 0 错误、0 警告；GLB 导出回读无错误，高度 8.86m。礁面 GLB 回读无错误。模型背面、准确尺寸和地质结构由单张透视原图推断，没有虚构几何匹配率或审美分数。

中间验收曾拦下玻璃的错误材质、外观登记遗漏和 3 次鱼群遮挡；已修复并重跑完整检查。失败图留在 review/rejected-acceptance，不作为最终效果。

## 对照原图的结论

水面不再是 v13 的灰白浅滩；灯塔有了连贯的结构、真实开口和材质分工；礁面从平滑坡壁转为带台阶和裂隙的形体。这些是基础资产变化。

整景仍明显低于原图：旧岸线依然有粗网格硬边和扫描岩体重复；阶梯、岸脚与地面之间的衔接仍像原型；部分礁面过于陡直、裂隙带有程序化痕迹；原图的宽阔礁台、金色侧光、冷色阴影与深色前景仍未建立。灯塔的灰泥磨损也需要进一步按参考分布调整。这轮不能报告成原图复现完成。

后续基础重做应优先岸线与岸脚连续形体、步道和码头整体结构、材质尺度与主光层次；先用固定镜头证明整体提升，再考虑装饰。

# 深海灯塔 v12：实机美术与原图差距

日期：2026-10-23。已实际接入 GitHub 岩石生成工具，生成模型、导入 Unity 并构建独立程序。画面仍明显低于原图质量。

## 本轮实际改动

- 使用 [Blender Rock Generator](https://github.com/blender/blender-addons/tree/b1fbf73a08cfb68b14bb328590a9bb6602d96916/add_mesh_extra_objects/add_mesh_rocks)，本地适配 Blender 5.2；六种模型各 1600 三角面，总计 9600。保存可编辑 Blender、GLB、精确顶点 JSON、来源与许可。
- 39 处高礁使用不同生成主体和单层破碎岩冠，替换三层相同扫描石的堆叠。近岸仍使用细节更好的原扫描石，六种生成模型没有整批替换所有岩石。
- 浅水增加斜视光程吸收，减少黄绿色；深水保持蓝色。以波面折射的光线密度生成焦散，替换多边形网线，并统一到沙地、岩石与珊瑚。
- 依实际显示的岩面重新落位，最终 239 丛新珊瑚、122 丛绿色海带。原有控制、物理地形和存档逻辑保持原版。

## 与原图相比，差距在哪

| 项目 | 原图 | 当前实机及优先修正 |
| --- | --- | --- |
| 主礁台大形 | 连续弯曲的礁台沿深沟展开，顶部宽，边缘破碎 | 堆叠重复已减少，但主体仍像独立圆钝石柱；应专门制作连续礁台模块，细化岩壁与海床交接 |
| 水体层次 | 透亮青绿浅滩、青蓝过渡、深蓝沟槽，波纹与反光有大小变化 | 色相更接近；深浅交界仍能看出地形折面，水面反射偏弱，焦散尚有纹理重复 |
| 生物群落 | 多尺寸珊瑚相互重叠，色彩集中成片，海带形成轮廓 | 已有三维群落，仍偏稀疏，板状/脑状珊瑚较像简化道具；需增加群落内部尺度和遮挡关系 |
| 灯塔、码头 | 灯塔有风化和附着物，木板不齐，支撑与杂物讲出生活痕迹 | 形体齐整、材质均匀；需独立重做塔身破损、木板边缘、栏杆与码头支撑，不能只再调色 |
| 光照 | 暖阳与冷海形成对比，局部亮斑引导目光到船和岸边 | 暖冷关系存在，整体仍均匀；船、码头缺少更明确的光照焦点 |
| 构图与前景 | 暗色近景植被、岩块包住场景，远近尺度清楚 | 缺少前景框景，海床空白较大；需在保留操作视野的前提下重组前景与群落 |

下一步优先级：连续礁台与海床过渡 → 珊瑚群落层次 → 灯塔/码头资产 → 光照与前景。继续安装通用审美打分器不能代替这些制作工作。

## 最终实机验收

独立程序检查通过，失败列表为空。原生 1920x1080、渲染比例 1.00，固定镜头 1200 帧平均 **86.22 FPS**，P95 13.78 ms、P99 15.58 ms；显卡 Intel(R) Arc(TM) 130T GPU (16GB)。这是指定场景的短时样本，不代表全地图长期性能。

原船控制器实航 15.75m；步行 42.59m，12 个检查点；上下船、穿洞检查通过。鱼群路线 14080 次检查无物理阻挡，洞内鱼体抽样 3520 次。新增珊瑚离鱼群路线最小余量 0.832m；模型顶部 -0.619m，位于水面下。新增岩石没有碰撞体。

对 v11 前的 76 个受保护运行时源文件复核哈希，全部未变。本轮原有运行时文件仅改外观岩石绘制和验收记录两处。六种模型检查 0 警告、0 错误，GLB 回读通过。

v11 同镜头样本为 92.02 FPS，本轮为 86.22 FPS，约下降 6.3%；本轮群落与材质均变化，未做逐项性能归因。

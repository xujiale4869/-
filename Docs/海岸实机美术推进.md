# 海岸实机美术推进记录
目标：在原游戏地图、海陆玩法和存档体系上继续修改，以确认过的“雾岬岛·东岸”参考图作为视觉方向。当前版本仍未达到参考图的最终实机质量。

## 当前体验入口
桌面：深海灯塔－立体海岸制作版.lnk
程序：Builds/CoastSliceV2/GuichaoBay.exe
参数：-coast-slice -screen-fullscreen 0 -screen-width 1920 -screen-height 1080
WASD航行；低速靠近东岸码头按F下船/回船；滚轮缩放；F6切换固定构图；F7查看模型；F8显示/隐藏帧率。
交互版本上限60帧。此制作入口使用VerificationMode，不写入正常进度。历史入口已另存，原正常游戏入口保留。

## 这一版做了什么
- 保留原地图、登陆点、环路、任务和船只控制，继续使用Unity 2022.3.62f3c1 / URP 14.0.12。
- 41处扫描岩石、6棵海岛树、58丛蕨类；水下改为3片疏密有变化的群落，共222组珊瑚、20只海星/海胆，并调整海带的高度、倾斜和间距。原有70条、4类新增鱼群及其他生态继续运行。
- 树冠按叶片与枝叶簇生成保留贴图的卡片，近中远三个LOD分别约13.98万、9.27万、6.43万三角形；修正卡片法线及LOD层级，近景保留全部叶片簇。
- 每丛蕨类的4个网格合为1个，保留几何和贴图，减少提交次数。
- 海面与海床分块裁剪，去除细分海床下的重复地面；细分波面后在顶点计算波浪法线，沙地减少重复采样。
- 阴影与深度通道只做必要的透明裁切；实心岩石背面剔除。水面反射最多30次/秒，镜头明显移动时立即刷新。
- 保留HDR、ACES、阴影、反射、折射、焦散、鱼群、植被。制作入口使用2倍MSAA，未降低1080p渲染分辨率。

## 性能实测：2026-10-20
设备：Intel Arc 130T GPU；1920×1080窗口，Release构建，UI和帧率显示开启，接电。
测试时解除帧率上限，每个视角预热360帧、测量1200帧；计时期间不截图、不写文件。
| 场景 | 平均FPS | 平均帧耗时 | P95帧耗时 |
| --- | ---: | ---: | ---: |
| 海岸固定视角 | 78.01 | 12.82ms | 14.67ms |
| 航行跟随视角 | 81.26 | 12.31ms | 14.26ms |
| 下船站立视角 | 60.09 | 16.64ms | 21.03ms |
下船视角是站在码头处测量，角色重力和碰撞继续工作；不是完整步行路线测试。航行性能样本由自动施加船速产生。
下船视角仍有明显波动，不能据此宣布全地图稳定60帧。前期1080p约29–32帧记录可作历史参考，但供电与测量时段未统一，不作为严格同比倍数。
原始结果及截图：Verification/coast-final-verified/。其中passed表示功能断言通过，不表示所有场景达到稳定60帧。

## 操作和画面验证
最终场景检查通过：材质支持、错误着色器像素、环路地面采样、新岩壁避让、东岸下船/回船均通过。真实油门控制器输入0.45、转向0，模拟6秒、300次物理步，船从(55,0,94)移动到(60.34,0,108.67)，位移15.616米；未记录到碰撞接触。录像逐帧截图不参与1080p性能计时。
长测中角色在下船点保持(46.00,0.69,94.00)，回船成功。自动验证隔离外部移动键输入，交互入口仍使用原有WASD控制。
早先未隔离输入的测试记录仍保留，其中出现角色离开码头；不能把该次失败记录当作通过。
补充检查改为通过BoatController的油门和转向输入驱动物理船，并记录模拟时长、物理步数、碰撞接触与位移；不直接设置船速来代替控制器检查。
画面已经人工查看：树叶为正常绿色，未见粉色错误着色器或明显海床接缝。视觉判断仍为“未达到参考图”。

# 深海灯塔 v13：连续礁台与群落推进

本轮实际修改 Unity 工程并完成独立程序验收。重点完成连续礁台、珊瑚群落、码头细节和展示构图；仍未达到用户原图的美术质量。

## 本轮解决了什么

- 用 8 块相接的海床网格连接主礁肩、侧壁和海床，新增 35044 个三角面，替代大部分独立圆钝石柱。保留真实岩洞开口及原碰撞，地形外观与玩法物理解耦。
- 修复新旧海床重叠产生的交错三角块；覆盖范围在颜色、深度、阴影通道一致裁切。植物落点改查实际显示网格，避免把隐藏的碰撞面当作可见海床。
- 珊瑚扩为 5 种，单套共 5020 面。最终 512 丛，实例三角面 570152，用大小错落和优势种群形成连片；保留 98 丛干净绿色海带。
- 码头板面增加磨损边角、窄缝和轻微错落，补了两盏岸边暖灯；加强灯塔下部雨痕、灰泥风化。板面外观替换保留原行走碰撞。
- 增加近岸前景树和展示镜头重构，使灯塔靠近画面上沿，码头与船向上移动，露出近景岩石。另存原镜头 reference-baseline.png，避免把相机变化混入同镜头比较。
- 深沟增加 108 条小银鱼组成弧形群，总鱼数 196。首轮路线被检查拦下后，缩窄活动带、调整水深，再验收通过。

## 实机检查

全部检查通过，失败列表为空。原生 1920x1080、渲染比例 1.00，新展示镜头 1200 帧平均 **70.97 FPS**，P95 16.09 ms、P99 18.07 ms。显卡：Intel(R) Arc(TM) 130T GPU (16GB)。v12 原镜头样本为 86.22 FPS；本轮增加群落并调整相机，不能把两者当作严格的单项性能归因。当前新增画面内容确有性能成本。

原船控制器实航 15.73m；步行 42.58m、12 个检查点；上下船、穿洞通过。物理与可见海床分别检查鱼群路线，31360 次可见海床抽样无阻挡，洞内实际鱼体 3520 次检查通过。新增珊瑚路线余量至少 0.748m，顶部最高 -0.630m，低于水面。

本轮仅改 6 个既有运行时文件，均为外观、生态或验收逻辑；其余 77 个既有运行时文件哈希不变，包括原控制、地形和存档相关代码。没有编辑原场景、碰撞预制体或原水深适配逻辑。珊瑚和海床模型检查均 0 警告、0 错误，GLB 导出回读通过。

## 对照原图仍差在哪

| 项目 | 本轮改善 | 剩余差距 |
| --- | --- | --- |
| 礁台 | 大形连续，石柱重复大幅减少 | 陡壁仍偏光滑、侧壁破碎层次不足；岩洞附近保留的旧岩体还需要统一 |
| 水与岸脚 | 修复交错面，焦散与折射更清楚，保留珊瑚暖色 | 浅水仍偏灰，浪沫与水面反射不足；岸脚和覆盖边缘仍有硬边 |
| 珊瑚 | 5 种轮廓、大小与色群，群落更连贯 | 部分块状模型仍像简化道具，细枝与花簇材质精度不及原图 |
| 建筑 | 木板边缘、暖灯、塔身风化已有补充 | 灯塔主体和窗门仍过于规整，码头支撑、岸边杂物仍缺生活痕迹 |
| 构图和光照 | 前景岩石、远处鱼群与船的位置关系更明确 | 暖冷光的焦点、前景暗部层次与原图的绘画感仍不足 |

单张透视原图不能测出精确三维尺寸，未见部分和比例均为推断；未使用或虚构审美分数。

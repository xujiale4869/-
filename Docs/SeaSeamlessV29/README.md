# v29 雾岬岛·东岸：连续海岸与航海 UI

独立场景 `CoastSeaSeamlessV29.unity`，程序 `Builds/SeaSeamlessV29/Guichao-SeaSeamlessV29.exe`。继承 v28 航行、建造与 v26.2 水面，旧 v28 程序和入口保留。

用户原包保存在 `Tools/SeaSeamlessV29/OriginalInputs/`。新系统按地形、原海床数据、UI、图标、桥接和验收拆成 partial 文件。原包中全场景自动加载、G 双重切换、反射错字段、透视相机改正交尺寸和旧 HUD 全局隐藏的问题已改为显式、限定 v29 的接口。

## 操作

- 常规开船滚轮缩放 8.5–34，真正调整现有透视相机的视场；钓鱼、室内及管理窗口保持原专用视角。
- B / G 进入或退出海湾营造；WASD 规划漫游，滚轮缩放 10–55；1–4 选设施、R 旋转、左键建造、右键拆除。
- L / 提灯图标只控制船尾灯芯、灯光和水面暖光，不再把整个 v27 珊瑚/港湾外观开关当作道具。
- Tab 鱼箱、F 上下船、Esc 暂停与原钓鱼 E / 鼠标流程保留。钓鱼收线/张力、鱼箱、暂停和展缸管理仍使用实际功能，并统一为航海边框。

## 连续海域与真实采样

按包内明确数值，v29 航行范围为 `X[-22,128] Z[-88,108]`，矩形面积 29,400m²，约为 v21 的 13.36 倍；没有沿用标题“15倍”或另一组注释坐标。实际可通行水域受地形/礁石影响，可建造区域由实时水深和碰撞决定。

编辑器从原场景中实际启用的地形网格进行向上表面的三角形栅格采样，记录来源网格数量、覆盖节点与最近覆盖距离。原区域下方的新海床参考真实高度的保守邻域下包络，再压低 0.09m，外围用 14m 平滑权重连接到南北海岸、深水沟、外海屏障礁脉及远东浅滩。原包注释声称扫描但实际只有解析公式，本次补上了真实采样，且不宣称百分百无接缝或与未提供原图完全一致。

海面为 420m 方形世界坐标波浪网格，海床覆盖约 181×220m；深层背景覆盖远景，西侧陆地另行延伸到可视范围之外。新地形在 v28 建造网格和布局加载前生成，避免用旧沙台判定后再换地形。建造网格范围 gx[-6,62] / gz[-42,48]，水深范围最多 0.35–6.2m，珊瑚保留最小生长深度。复用工程中完整的低面数扫描岩模型，派生六种轻微轮廓与比例变化后用于海岸和外海礁带；未把大片地形表面当成独立岩石。岩石沿用原三平面贴图与法线材质；复用原岩沙贴图、四带珊瑚色盘、绿色海带及整棵双材质红枫。新植物采样可见实体岩面并限制尖端高度。

## UI 与存档

UI 使用 7 个可复用的 128px SDF 轮廓图标、圆角暗金双边框、无底框地域标题、资源胶囊、左下工具槽和右下建造抽屉。字体沿用已授权 Noto Sans SC，正文和成本在参考 1920×1080 画布中至少约17–20px。选中用边框与菱形标记共同表达，停用保持可读；保留真实交互提示和错误原因，不显示实现调试参数。新旧常驻 HUD 不同时覆盖海面，弹窗及钓鱼反馈不因换皮消失。

普通玩家收藏继续沿用 v21 存档。建造新存档为 `sea-bay-expansion-v29.json`；首次无该文件时复制旧 v28 布局，旧文件不修改，已有建筑按新海床重建桩基/底座。验收在加载前分别隔离玩家和建造存档，不用正常进度摆放测试物品。

UI 风格为本轮选定方向的可运行初稿；视觉证据/独立评审与限制另存。尚未进行独立新内容迁移实验，不称整个游戏视觉体系已完成验证。

## 本轮验证与限制

最终 `Verification/seamless-v29-review07` 的 58 项运行检查与 `seamless-v29-native02` 的 12 项真实 Windows 输入检查通过，两次运行均 0 错误、0 警告。原生 G 进入、W 漫游、3 选珊瑚、R 旋转、左建右拆、G 返回及滚轮改变真实透视视场均已执行。首轮功能通过仍发现标题空白和海床穿出，review04 仍有植被不足；review05 南北原地形块边缘断面与钓鱼阶段提示冲突，review06 已修断面，review07 再修当前操作提示优先级，均作为草稿保留，不作最终依据。

从 35 个原网格采样得到 28,561 个覆盖节点；新增 46 岸岩、61 外海礁、36 珊瑚组、18 海草组、12 红枫。植被逐点搜索水下实体表面，避开露水礁顶与深沟。六个扫描岩变体每个约 702 三角形，使用现有闭合低面数模型；没有把高面数地形片的简化失败称作优化成功。

原生 1920×1080 固定宽视角每状态 480 帧：航行 71.84 FPS / P95 15.70ms、规划 67.00 FPS / P95 17.27ms；这是短时采样，不作全地图、长期或 4K 结论，也不与镜头不同的旧版直接比较。增量构建有 1 项既有 API 警告，完整构建有 24 项既有警告，不能称全工程无警告。

测试前隔离玩家/布局存档；交付前对 2,967 项旧工程文件核验，只允许六处限定 v29 的源码接入，其余预期保持一致，并校验正常收藏/旧布局和旧 v28 exe、Assembly-CSharp。第一次普通启动会将 v28 布局复制到 v29 独立档，之后旧 v28 布局继续保留。

截图覆盖航行、建造、钓鱼、鱼箱、暂停、展缸，航行/建造另有原生 720p。独立视觉检查原文及证据在 `VisualReview/`。整体环境和人物沿用旧资产；UI 仅作可运行初稿，未完成全状态图标对照、全部 720p 弹窗/钓鱼测试和独立新内容迁移验证，不称全游戏美术体系已定稿或获得用户认可。外海无新增鱼点/登船点，蟹笼暂无自动收益、建材暂无补给采集链；自由建造也不保证任意步行线路连通。

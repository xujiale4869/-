## 接入方式

采用 Codex 本地 Agent Skills 机制；技能文件放在用户技能发现目录，无需增加常驻 MCP 服务。按照 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)，Codex 会发现本地技能变动，下一条消息可以尝试调用；若列表未更新，重启 Codex。当前回合不能证明下一个回合的自动发现结果。

本项目的 [AGENTS.md](../AGENTS.md) 已记录任务选择、历史审美方向和可用运行环境。后续在这个工作目录执行美术工作时，有明确的工具入口和检查要求。

复用现有 Blender 5.2.2 LTS、FFmpeg 和 Codex 自带 Python 图像依赖。普通 PATH 中的 Python 缺少 NumPy，已在项目指引中指定经过验证的 Python 路径。

## 其他候选的取舍

也读取了 [Aesthetic Scorer MCP](https://github.com/maroun2/aesthetic-mcp) 和 [FusionVisionMCP](https://github.com/Whoawhen/FusionVisionMCP) 的说明与部分实现。前者提供多维图像分数，后者包含图像分析与审美打分；本轮未安装。根据它们的模型用途和本项目需求，我的判断是：通用图片分数不能直接判断珊瑚造型、模型接缝、背包交互或游戏可读性。此次优先接入能产出对照证据与游戏资产的工具。

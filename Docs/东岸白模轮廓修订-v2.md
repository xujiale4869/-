# 东岸白模轮廓修订 v2
日期：2026-10-21。

本版依据用户在成品风格目标图上标出的红线，修改中央礁台与深沟对岸，并增加真实贯通的水下岩洞。目标图为AI示意，Screenshots-Actual内为Unity实际运行截图。

## 当前改动
- 两岸采用不同的大幅转折、伸出、回缩和局部收窄，替换近似平行的两排岩体。
- 岩体增加高低侧阶和局部倾斜，避免单一竖直断面；减弱重复的水平凸缘。
- 岩洞有实体拱顶、内壁、两端出口；周围岩体给通道留出空间。
- 22个低面数灰色鱼形测试体沿贯通路线往返。它们用于检验空间，尚不是成品鱼群或完整生态。
- 船、码头、灯塔的原坐标和原角色控制器继续使用。

## 体验
桌面入口：深海灯塔－白模验收版。
WASD航行/步行；靠近栈桥、低速时F上下船；滚轮缩放。
F5正交/弱透视；F6参考/跟随；F7岩洞观察；F8帧率；F9水面开关；F10界面；Home复位。
交互版限60帧，白模不写入正常游戏进度。

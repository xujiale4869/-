# v15：岸线、石阶和礁面基础调整

2026-10-24。按用户要求直接修改实际Unity工程，停止增加装饰种类和投放尝试次数。用户认可的v12水面核心及0.0022折射保留。

## 本轮变化

岸脚视觉地形从0.65m网格细分到0.325m，岸边的陆/水高度断面改为连续过渡。原物理网格仍为74992面；新的可见地形299968面，4块网格与碰撞资源独立。陆上步行带采样高度改动为0.000m。没有调整原来的地形构造、船控、存档和主玩法源代码。

礁壁重新设计横截面，加宽肩部、把四级急降改为较长的分段坡面，并加入两处鞍部和倾斜岩层。8块共36292面，面数与v14相同；坡度超过70度的面面积占比由44.5%降至31.1%。这是几何统计，不能当作美术评分。局部仍然陡直，特别是洞口和对岸。

石阶的规整方盒外观换为分块、有边缘磨损的石板，沿原台阶碰撞顶面制作。地被收回过亮的黄绿，主光略降低角度、环境补光略变冷。岸壁材质试验出现浅色坡面，已撤回，最终保留稳定的地表材质结构。水面着色器SHA256与v12完全相同，水下几何和整体光照变化使整幅画面不可能逐像素相同。

珊瑚上限仍512、最终512；绿色海带按新可见表面重采样后122丛。没有增加种类和散布尝试次数，数量变化来自落点与可见表面变化。

## 与原图仍存在的差距

这轮减轻了岸边锯齿、规整台阶与连续幕墙感，但尚未达到原图质量。主要问题仍是扫描岸石轮廓重复、洞口附近的大块平面、礁面材质缺少清晰的岩块结构、码头过于笔直规整、珊瑚色彩层次不足，以及深色前景与暖冷光焦点不够。新的礁坡部分仍像连续坡壁；下一轮需要逐段塑造大的岩块和凹口，不能靠更多噪声或珊瑚填满。

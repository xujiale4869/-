# v27 港湾与礁区

独立场景 `CoastSeaHarborV27.unity` 继承 v26.2；构建为 `Builds/SeaHarborV27/Guichao-SeaHarborV27.exe`。桌面“深海灯塔－最新版”和“深海灯塔-港湾与礁区-v27”进入此版，旧 v26.2 程序与入口保留。产品名继续沿用 v21，以保留正常存档位置。

- 船尾木灯架、开放式灯笼框架、暖色灯芯、船舱木箱和盘绳。随波视觉船身带动全部装饰；灯笼根据船体局部加速度和风摆动，不增加刚体或碰撞。
- 沿既有栈桥木桩布置下垂绳栏，保留靠船处开口；桥头有斜撑高灯柱和木桶货箱。小馆入口增加木屋檐与旧木纹。
- 原有珊瑚按紫、橙、薄荷绿、暖金四种群落材质显示。新增六组分叉及层叠珊瑚、五组四叶海带束（一处因海床高度预算跳过），收成两片浅礁。按可见海床网格落根，并限制尖端高度；海带保持绿色。
- 两盏无阴影点光源的位置、颜色和范围同步给专用木材与水面 Shader，计算局部暖光和反光；没有新增反射相机、阴影贴图或逐帧全场景扫描。

按 **F8** 开关 v27 装饰与礁区材质；关闭时恢复全部被替换的材质槽、旧灯网格和原水面 Shader。**F7** 仍为 v26.2 水面调参，**F6** 为水面材质对照，**F9** 显示帧率。水面默认焦散 `.92`、波光 `1.85`、聚焦 `72`、泡沫 `.95` 保留。

## 资产和接入修正

用户原包完整保存在 `Tools/SeaHarborV27/OriginalInputs/`。实际生成四个 FBX、两张颜色贴图、四个可编辑 Blender 源文件。船灯架、绳栏、盘绳与屋檐为运行时几何；没有宣称原包注释中的六个整件 FBX 都已生成。两张颜色贴图不等同于完整 PBR 贴图组，叶尖透光也是着色近似。

修正 FBX 导入方向/单位：Blender 导出四个基准空节点，Unity 据此烘焙为米制 Y 向上的原生 Mesh，并核对提灯 0.43m、海带 1.85m。PNG 的根到尖渐变修正上下方向。灯罩采用开放框架，避免不透明外壳遮住灯芯。原稿五根粗枝的珊瑚进一步增加次级分叉和低矮盘层。

原包针对旧版逐根立柱查找；当前栈桥已合并，改用已接纳 v16 的实际木桩锚点。绳栏合并为两块网格，靠船端留开口。精确覆盖的旧桥头灯只替换可见网格，原碰撞保持不变。新版仅在 v27 场景或显式 `-harbor-v27` 参数启动。

珊瑚色盘按 Renderer 群落分配，避免逐顶点哈希把一丛珊瑚切成碎色。实例材质保留 instancing；若出现旧版 CoastReefCanopy，其私有组只在初始化时访问并保存恢复。海带和珊瑚的颜色、深度、法线通道共用同一位移及时钟；暂停冻结摇摆、灯光闪烁和水下动画。

正常存档 SHA256 前后相同；基线中 2772 项既有源码、资源、场景、设置和包清单全部保持原哈希。新装饰没有碰撞体。实际控制器航行、下船、栈桥步行、重新登船通过。测试采用唯一临时存档，不往玩家收藏添加验收鱼。

首轮海床筛选过窄，新增群落为 0，已修正；首轮 F8 原生输入因前台窗口保护中止，没有发出按键。失败/草稿结果仅作追溯，不作为最终验收。第二轮功能检查已通过，随后因近景粗枝及散点布局继续精修；正式交付以这里的最终 Runtime / NativeInput 证据为准。

## 再构建

在工程根目录执行 `Tools/SeaHarborV27/Rebuild-Harbor.ps1`，默认只核对已接纳输入，不恢复覆盖。加 `-Build` 使用已保存的 v27 场景构建；显式 `-Regenerate -Build` 会重新生成 Blender 资产、烘焙网格和场景，产物需重新实机检查。冻结清单依赖现有工程，不是完整工程备份或逐字节构建复现保证。

普通 Unity 入口：`Deepsea.Editor.SeaHarborBuildV27.Build`。仅显式 `ImportAndBuild` 才重新导入/烘焙并从 v26.2 复制场景。构建保留原项目设置，复制已有第三方许可至新程序目录。

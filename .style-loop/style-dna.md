# Construction rules K
Reference palette: deep navy #10272D, brass #C7A870, warm ivory #F3EBDD, active muted teal #295C55. Thin paired warm-metal borders, rounded 10–14px corner families, compact surfaces; no full-width opaque bottom HUD strip. Readable text gets a subtle dark outline, no ornate display font. Line icons share 2–3 logical px stroke at 40px display; lantern cage, linked rings, angled rod/line, compass star, pier piles, branching coral and pot/buoy are distinct silhouettes. Selected controls change border + marker + text; disabled controls dim but keep labels. UI positions respect world interaction, and progress/modal functionality stays visible. Existing 3D environment material/character grammar is preserved rather than claiming a new whole-game style.

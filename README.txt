灯种守夜 · Lantern Ward
原创小型塔防 / v0.1.0 / 2026-10-04

【启动】
Windows 10 / 11，64 位：双击 LanternWard.exe。
无需安装 Python、Node、Godot 等开发工具。
程序使用电脑已有的 Microsoft Edge，打开独立游戏窗口。
游戏画面、逻辑和音效全部嵌在程序里，无需联网加载素材。
如果没有 Edge，程序会尝试用默认浏览器打开游戏。
备用启动：使用当前版本的 Chrome 或 Edge 打开 LanternWard.html。

【这是怎样的游戏】
在微光苗圃里，守护一颗发光的灯种。
夜潮沿小路接近温室；你用植物灯塔编织防线，让种子等到天亮。
第一版是一张完整关卡：12 个塔位（其中 4 个需清障）、3 种塔、
每种塔 3 个等级、4 类敌人（包括最终首领）、12 波、一个主动技能。
有标准 / 轻松两种模式、音效与轻音乐、暂停、倍速和通关星级。
采用原创矢量场景、动态萤火、植物灯塔、敌人动画与战斗光效。
题材与美术为原创，只借鉴塔防游戏的通用玩法思路。

【玩法】
1. 点击圆形石台，在右侧选择灯塔。
   萤灯塔：70 灯露，单体追踪，攻击快。
   爆蕾塔：110 灯露，范围攻击，适合成群敌人。
   月露塔：95 灯露，伤害较低，但能减速敌人。
2. 点击已建成的灯塔，可以升级两次或卖出。
   卖出返还全部投入的 70%。
3. 灯塔自动攻击，优先攻击最接近温室的敌人。
   空闲时自动清理射程内的枯灯木 / 结夜晶。
   清理障碍可获得灯露和新的塔位。
   点击障碍，可以把它标为优先清理目标。
4. 布置好后点击“迎接夜潮”。每波之间可以自由准备。
5. 点击左下角“晨光降落”，再点击地图选择位置。
   范围伤害 190，同时减速；冷却 26 秒。
6. 温室初始有 20 点光芒，降到 0 就失败。
   守住 12 波即可通关；剩余光芒越多，星级越高。
   光芒 18–20：3 星；10–17：2 星；1–9：1 星。

【快捷键】
空格：暂停 / 继续
N：下一波
D：切换 1 倍 / 2 倍速度
Q：晨光瞄准
M：开关声音
F：切换全屏
Esc：关闭说明 / 取消选择 / 取消技能瞄准
右键：取消选择与技能瞄准

【存档】
每波结束自动保存；准备阶段的建造、升级等也会保存。
战斗中退出，下次会从这一波出发前的准备检查点继续。
最高通关光芒单独记录；通关或失败后本轮存档结束。
原生启动器在当前用户的 LocalAppData/LanternWard 下存放游戏文件，
Edge 独立配置内保存进度。删除此目录会清除存档。
直接打开 HTML 与使用 EXE 的浏览器配置不同，存档不共享。

【当前版本边界】
这一版使用系统浏览器渲染，没有另附完整浏览器运行时。
没有英雄、兵营阻挡、关卡选择、技能树或联网功能。
下一版可优先新增第二张地图与塔的升级分支。

# 深海灯塔 · 归潮湾 Unity 原型 v0.1

这是按“接入审美工具”讨论中最新的海面村镇与浅海自由航行方向制作的 **Unity 原生 C# 工程**。当前实现的是一片连续可航行的浅湾和一个可以成长的归潮村。后续可以在同一工程中扩展船只、建筑、海域和下潜。

## 在 Unity 中打开

1. 解压完整工程，保留 `Assets`、`Packages`、`ProjectSettings` 三个目录。
2. Unity Hub 选择“打开 / 从磁盘添加项目”，选择包含这三个目录的工程根目录。
3. 本次目标编辑器为 **Unity 2022.3.62f3c1**，与当前电脑安装版本一致；使用 **URP 14.0.11**。第一次打开需要解析 Unity 官方软件包。
4. 等待导入完成，打开 `Assets/Deepsea/Scenes/GuichaoBay.unity`，点击播放。也可使用菜单“深海灯塔 → 打开归潮湾”。

首次导入会配置 URP、窗口尺寸、旧输入 API 和场景构建入口。场景的船、村庄、礁石与交互物由 `WorldBuilder` 在播放时生成。可调数值集中在 `Assets/Deepsea/Config/BaySettings.asset`，布局在 `WorldBuilder.cs`。

Unity 6 的升级尚需单独验证并升级对应 URP 包。本次不要求更换已安装的 2022.3 编辑器。

## 可以玩到的内容

- W/S 控制推进、减速和倒车，A/D 打舵。保持惯性，拖带时速度和转向变化。
- 自己决定探索顺序和航路；西侧沉船滩、东侧荧鳞礁、北侧旧航标通过开放水面相连。
- Q 短距探测；目标标签和小海图只显示近处或已探测线索。海面场景有环境可见度，不沿用旧水下版本“灯外全黑”的表现。
- 低速接近目标，E 回收小件、接应遇险者、连接故障船拖缆、记录鱼群或修复航标。
- 乘员位与货舱分别计算。一次只拖一个目标，X 可以解缆，目标留在海上。
- 在村码头附近减速，E 手动靠泊；统一卸货、安置乘员和船体、免费维修补给、保存村庄。
- 船坞轻绞盘增加可见吊具，改善拖带并允许重型设备回收；海图屋增加观测设备并扩大探测范围。
- 可建设一座缆网台，主动开启一次守港演练。网台自动拦截，近船探测可以扰动目标；演练不会自动打断探索。
- 保存已结算材料、居民、船体、建筑、航标和已取走的唯一回收物。退出时船上未靠泊的收获不会自动进入村仓。
- Esc 暂停、调节音乐和交互音量；M 俯看海图；滚轮调节镜头。村船接回会放弃未结算收获，保留永久建设。

建议尝试：先在内湾回收构件，探测沉船滩并救援；返村建绞盘，再回到重型设备所在水域。也可以先去荧鳞礁观察，带记录回来建海图屋。两条探索顺序都能推进建设。

## 美术与技术边界

采用蓝青灰海面、低矮木石屋舍、湿润礁石与局部暖灯。工作艇、双坡屋顶、栈桥、吊具、遇险船和鱼群使用原生网格与几何构造，海面使用自定义 URP 着色器；船尾波保存在世界空间。真实露礁与沉船有模型对应的碰撞，海床色块、灯束和海面没有隐藏碰撞。

这是首次 Unity 可玩原型，美术尚未达到最终制作质量，也不表示达到《奥日》或参考图的完成度。当前没有深海下潜、真实折射水体、完整 NPC 行为、自由摆放建筑、天气潮汐、完整巨物战役或二级船。音轨是用于操作与音量验证的程序合成氛围声，后续需要正式声音制作。

海域外围通过可读海况提示和回流提醒一级船的范围，不设置无形碰撞墙。守港演练是主动触发的机制样本，数值尚未经过多人试玩平衡。

## 构建与验证

- Unity 菜单“深海灯塔 → 构建 Windows 试玩版”，输出 `Builds/Windows/GuichaoBay.exe`。需要安装 Windows Build Support。
- 菜单“深海灯塔 → 检查规则”检查独立货舱与乘员位、重复拾取、结算幂等、建设费用、升级作用和存档恢复。
- `Tools/Unity-Check.cmd Import` 用真实编辑器检查导入、规则、场景和着色器消息。
- `Tools/Unity-Check.cmd Play` 自动进入播放模式，检查救援、拖带、交付、建设、探测，再用实际 Unity 相机输出图片。
- `Tools/Unity-Check.cmd Build` 构建 Windows。第二个参数可指定其它编辑器的完整路径。

实际验证结果见 `Verification/verification-summary.md`；未完成的检查会明确列出。启动器与工程本身不修改安全设置。

## 主要代码

| 文件 | 职责 |
| --- | --- |
| `GameDirector.cs` | 探测、交互、返港结算和建设流程 |
| `BoatController.cs` / `Towable.cs` | Rigidbody 航行与 SpringJoint 轻拖带 |
| `GameRules.cs` / `SaveStore.cs` | 纯规则、永久进度和带备份的存档 |
| `WorldBuilder.cs` / `VisualFactory.cs` | 浅湾布局、真实障碍与造型 |
| `WorldInteractable.cs` | 回收、救援、设备、航标和观察 |
| `FollowCamera.cs` / `GameHud.cs` | 随船镜头、海图与中文界面 |
| `Wildlife.cs` / `AmbientAudio.cs` | 鱼群、尾流和原型音频 |
| `HarbourDefense.cs` | 单次可选守港机制 |
| `ProjectSetup.cs` / `Verification.cs` | Unity 导入配置、构建与验证 |

本工程的游戏代码、模型生成代码与自定义着色器为本次编写；没有复制此前网页实现中的第三方 GGX 代码，也没有把旧潜艇方向图当作海面工作艇。Unity 与 URP 按各自官方许可使用。本工程未依赖 REA。

# 深海灯塔 · 水面与主体材质 v6

本包是既有 Unity 2022.3.62f3c1 / URP 14.0.12 工程的源码补丁与实机验收记录，不是完整工程或独立播放器。播放器输出为 Builds/CoastArtV6/GuichaoBay-ArtV6.exe。

## 本轮变化

- 水面从统一透明颜色叠加，改为读取实际水下画面，按 RGB 深度衰减合成，并加入轻微屏幕空间折射。
- 浅海减少灰褐色透射，增加青蓝色随深度的散射；缩窄岸边泡沫并降低覆盖强度。
- 折射颜色缓冲使用全分辨率，水面材质使用两层滚动波纹纹理，结合环境反射与岸边碎泡沫。
- 尾流方向跟随船朝向，强度跟随真实水平速度；停船时不保持运动尾流。
- 原扫描岩石外观补充水下焦散照明。
- 灯塔墙面调整为更浅的石灰墙，减弱大块褐色纹理和凹凸。
- 小船使用独立的旧木材与暗青色船舷材质，区别于码头。

水面反射来自环境贴图，未新增平面反射摄像机。折射来自当前屏幕中的不透明场景，属于屏幕空间近似。船与灯塔仍沿用现有模型，本轮没有把材质修改视为完整模型制作。

## 使用

已有 v5 工程中关闭 Unity 编辑器，运行 Install-CoastArtV6.ps1，再运行 Build-CoastArt.ps1。脚本校验或下载项目使用的两套 CC0 2K 贴图，并通过 Deepsea.Editor.CoastMaterialsBuild.Build 构建现有验收场景。

不要调用会重新生成关卡几何的 CoastBlockoutBuild.Build。

运行参数：

`-coast-materials -coast-ecology -screen-fullscreen 0 -screen-width 1920 -screen-height 1080`

WASD 操作，F 上下船，F2 开关生态，F4 对照白模，F9 开关水面。高分辨率窗口仍限制三维渲染像素预算到约 1080p，具体采样分辨率见验收报告。

## 仍有的差距

小船和人物模型仍简化，灯塔结构及植被造型尚未统一到参考图水平；水体缺少真实远景倒影，泡沫与尾流仍是实时着色近似。参考图是美术目标，实机截图才代表本版结果。

## 验证方式

性能以 1920×1080 窗口、URP renderScale=1、固定参考镜头、无帧数上限采样 1200 帧；截图编码不计入定时采样。航行与上岸验证恢复到实际游玩 60 帧上限。精确结果见 evidence/result.json。此处不是全地图、全时段最低帧率承诺。

Verify-Final.ps1 对生成后的 179 个岩石外观进行鱼群身体路径复核，再导出实机对照与已验收文件哈希记录。该脚本使用当前 Windows 项目路径，需要在其他设备上调整路径。

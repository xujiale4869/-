# 海湾生活 v24：海面层次与性能样板

日期：2026-10-28。用户否定v23海浪滚动感、水面与水下层次及性能表现，本轮以这些反馈为验收对象。v24仍待用户实际评价，不把功能检查当作美术认可。

桌面入口：**深海灯塔-海面层次与性能-v24**。程序：Builds/SeaSurfaceV24/Guichao-SeaSurface.exe。F7切换v23/新水面；F9显示或隐藏帧率。原v23入口和程序保留。正常产品名、存档位置和数据格式继续沿用v21。

## 画面方向与实际实现

- 海面本身具有明确主浪方向、波峰推进和受浪面朝向影响的反光。Gerstner三层波幅总上限0.29m；保留原细分水网格，未堆叠海面网格数量。
- 浅水可见度按真实水深、浪面朝向及浪峰变化；浅礁、海带、鱼影隔水显现，深处逐渐被青蓝水色遮住。水面不是统一透明度的覆盖层。
- 双向细波与主浪分工，岸线泡沫受深度交界约束；没有随机黄色/白色碎光层。
- 保留红枫海岬、干净绿色海带和既有船钓等玩法。船身、尾迹和浮漂接同一CPU波形；CPU反求水平位移，GPU在既有网格上插值波面法线，不宣称完整流体模拟或逐像素解析曲面。
- 增加水下材质细节分级：水深0.25–0.85m渐变到几何法线与主要漫反射，保留原轮廓、贴图、颜色、主要阴影和珊瑚色彩补偿。岸上及水下相机使用原完整着色路径。四份新shader与运行时材质克隆独立于原资产，F7可恢复原材质。

## 性能改动

原版主动锁60，之前的59.84FPS不是不限帧能力测量。此次目标帧率-1、vSyncCount=0，FrameTimingManager启用，记录实际窗口/目标尺寸、GPU耗时和P95。

保留主画面renderScale=1，使用FXAA替代4倍MSAA；水下折射使用半分辨率颜色副本，主画面和UI保持全分辨率。水下材质减少被海面遮住的法线、遮罩和BRDF细节计算；屏幕空间接触阴影保留原样本数/法线精度/强度，改用现有单次Kawase滤波。轮廓边缘与旧MSAA有取舍，不能称为像素等价。

### 1080p实测

Intel Arc130T，实际窗口/相机1920×1080，同一诊断程序、同镜头；每段80帧预热、480帧测量。帧率包含运行开销，GPU耗时另列；有热状态/时钟和时间顺序波动，使用重复段给出范围。

| 状态 | FPS | GPU ms | P95帧间隔 ms |
|---|---:|---:|---:|
| v23-original-4x | 58.53 | 14.86 | 20.60 |
| v24-water-FXAA-half-refraction | 134.34 | 6.96 | 8.45 |
| v24-depth-budget | 145.99 | 6.38 | 7.67 |
| v24-final-contact-filter | 147.55 | 6.30 | 7.64 |
| v23-original-4x-repeat | 65.03 | 13.24 | 16.40 |
| v24-optimized-repeat | 148.92 | 6.25 | 7.44 |

旧状态58.53–65.03 FPS；最终状态147.55–148.92 FPS。主要改善来自渲染设置与材质预算，单换水面着色器对旧设置的性能改变较小。诊断开关数据在runtime/1080-result.json，不把简单差值当作精确单个Pass计时。

### 4K场景测试

4K窗口请求被系统限制为2880×1800，因此使用3840×2160离屏场景目标，再显示到本机窗口；UI与呈现为本机窗口尺寸。不是4K显示器原生呈现或全地图保证。目标格式读取自URP实际相机描述，B10G11R11_UFloatPack32，renderScale=1。早期ARGBHalf目标的4K草稿不作最终结果。

| v24-water-original-4x | 17.11 | 48.03 | 67.42 |

**最终4K场景约56.42 FPS，P95 19.35ms，尚未达到稳定60FPS或4K高刷要求。** 不能用GPU单独耗时换算的帧率替代整套运行帧率，也不以本次结果宣称已匹配其他成品游戏性能。

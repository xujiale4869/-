# 深海灯塔 · 岸壁收边与水下植物 v9

这是 Unity 2022.3 / URP 14 项目基于 v8 的源码补丁和实机验证记录，不是完整工程。目标是修饰参考区域的直线断面，并减少岸上扫描资产与水下平涂植物的割裂。第三阶段美术尚未达到目标参考图。

## 实现

- 沿原地形的两级台地边缘摆放 UV 完整的扫描岩石外观，采用大小、角度和错位变化，分为宽阔、彼此重叠的上下两层，减少尖直的轮廓。仅添加视觉，不改动已验收地形或碰撞体。
- 每个岩石实例检查全部渲染顶点到原步行路径的距离，保留至少 2.6m；避开灯塔门前。只在原岸线内修饰断面，不遮蔽穿洞鱼群。
- 新建 `CoastMarine` 独立水下植物材质，接入绿色叶面贴图。叶片有纵向弯曲、横截面起伏、真实 UV 和按根部权重计算的水流摆动。海带由主茎和错落侧叶组成。
- 海草改用曲面长叶；海绵改用更细的截面、变化的轮廓与较深的口部。珊瑚色彩更克制，叠加沿用的扫描岩石细节纹理。它仍是自建珊瑚模型，不是新的珊瑚扫描资产。
- 新叶面是本项目使用内置 ImageGen 生成的模型贴图，不是实机模拟图或摄影扫描。按用户反馈放弃了褐色斑驳测试稿，正式包仅含干净绿色版本。
- 继续沿用 v8 草地、路径、树木、减面蕨类、小船与人物以及水面效果。

## 构建

基于已验证的 v8 工程，关闭 Unity 编辑器，运行 `Install-CoastArtV9.ps1`，再运行 `Build-CoastArt.ps1`。安装脚本核对原源码、备份受影响资源，并安装包中的绿色贴图。

构建入口：`Deepsea.Editor.CoastMaterialsBuild.Build`。不要运行会重新生成关卡的 `CoastBlockoutBuild.Build`。

输出：`Builds/CoastArtV9/GuichaoBay-ArtV9.exe`。

参数：`-coast-materials -coast-ecology -screen-fullscreen 0 -screen-width 1920 -screen-height 1080`。

## 操作与验证

WASD 航行/步行，F 上下船。F8 开关岸壁收边，F3 开关 v8 岸上地表和植被，F2 开关生态，F4 白模，F6 参考镜头，F7 岩洞，F9 水面。

固定参考镜头以原生 1920×1080、renderScale=1、无上限采样 1200 帧。正常游玩保持 60 帧上限，大窗口仍保留约 1080p 三维渲染预算。截图编码不计入性能采样，数据不代表全地图最低帧率。

检查原航行、12 个步行点、上下船、原鱼群穿洞、179 个扫描岩石外观与 334 个受保护文件。新增检查为岸壁外观数量、逐顶点路径净空、材质支持以及水下网格 UV。`evidence` 中为真实 Unity 独立播放器截图与检测报告。

## 本次实测

- 原生 1920×1080、renderScale=1、1200 帧：平均 94.09 FPS，P95 13.15ms，P99 14.99ms。
- 新增岸壁外观 53 块、159000 三角形，全部渲染顶点到原步行路径的最小距离约 4.89m。
- 水下植被和珊瑚共 165324 三角形；海带 92 丛、海草 190 丛、珊瑚 68 丛，均为原样片范围内的视觉层。
- 原航行、12 个步行点、上下船、3520 次穿洞鱼体采样、14080 次生态路线采样通过，334 个受保护文件全部未变。
- 实机仍能看到局部地形交接和模型轮廓问题，需要继续做人工美术整理。

## 素材

`Assets/KelpBlade-Albedo.jpg` 是本轮实际使用的 1024×1024 RGB 叶面贴图。生成来源、处理过程及提示词记录在 `Assets/source-record.json`。提示词要点：新鲜健康的绿色海藻叶面，柔和纵向叶脉、低对比、均匀漫射光；无褐斑、锈蚀、污点和场景背景。使用内置 ImageGen，未使用 API/CLI 生成。

扫描岩石、树木、草丛、蕨类、船模、地表和衣料沿用 v8 及此前版本的来源记录。构建脚本继续校验官方来源文件；本包不包含这些第三方原始大文件。

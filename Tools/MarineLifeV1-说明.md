# 深海灯塔：海洋生物更新 V1
这是现有 Unity 工程的增量更新备份，不是独立完整游戏。
## 已接入
- 两处共 42 条浅海鱼：群游、避障、船靠近时散开，随波面上下变化。
- 小群飞鱼：五条错时出水、展开胸鳍滑翔、入水，路线与速度有差异。
- 出入水水滴、逐渐消退的局部涟漪和水面明暗扰动。
- 新增生物不携带碰撞体；飞行路径预先避开岛屿、船只和栈桥。
## 在游戏中查看
从归潮村出港，前方浅水有一处鱼群；东侧荧鳞礁观察点保留另一处。
离港后在开阔海面航行，飞鱼偶发出现。地图总览、上岸和暂停时不会新增飞鱼事件。
自然事件成功触发后约 27～44 秒再次尝试；周边空间不足时会推迟。
桌面“深海灯塔－水面改进版”与“深海灯塔－海洋生物版”指向本版。
桌面“深海灯塔－飞鱼演示”可查看本版实机录制。
## 恢复或迁移
先备份工程，再将本包 Assets、Packages 的内容合并到同一版本工程。
需要 Unity 2022.3 / URP 14；依赖现有 Deepsea 游戏代码与 Boat Attack 水面文件。
编辑器构建入口 Deepsea.Editor.MarineBuild.Build 会重新规范化上游鱼模型并生成 Windows 构建。
本包不包含完整旧工程或 Windows 可执行程序。
## 验证
Verification/marine-life-v1/result.json 为本次 Windows 实机自动检查结果。
检查覆盖模型导入、鱼数、遇船反应、五条飞鱼落水、十次出入水扰动、涟漪消退、波面同步、岛屿路径拒绝和自然事件触发。
已检查正常缩放和近景截图。这些检查不代表完成长期游玩或帧率基准。

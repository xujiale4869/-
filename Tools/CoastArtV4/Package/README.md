# 深海灯塔：美术统一 v4 源码检查点

状态：已编写，尚未在 Unity 编译或实机验收。远程设备在写入项目之前离线，当前电脑上的 v3 玩家版本没有更新。本包不是可执行游戏，不包含新版本实机截图。

## 本轮修改

- 岩岸：降低扫描岩石的纹理反差和法线强度；利用坡度、高度和不规则斑块分布苔藓，使裸岩与植被之间有覆盖过渡。
- 水体：调整浅水与深水的青绿色阶，减弱铺满海底的焦散线和接触泡沫，让礁台和鱼群更容易辨认。
- 木材：降低橙黄色，增加风化灰褐色、木纹与板间色差；校正侧面的取样方向。
- 灯塔：墙面增加石灰斑驳和雨痕；添加窗套、窗框、门板、灯室支架、透镜、围栏环和屋顶细节。透镜使用发光材质，没有新增实时阴影灯。
- 码头：补充铁箍、钉头、系缆桩、绳圈和侧面斜撑，中央行走区域保持开放。
- 植被：压低黄绿色，调整叶片光照与裁切，等待实机检查树冠的噪点和整体体积。

新增建筑细节合并为 3 个渲染对象，不添加碰撞体。F4 灰模对照会隐藏新增外观并恢复原灯室比例体。地形、洞口、鱼群路线、场景相机与已有碰撞资产没有纳入修改包。

## 安装与验证

针对既有 v3 Unity 2022.3.62f3c1 / URP 14.0.12 项目。

1. 关闭 Unity 编辑器；运行 `Install-CoastArtV4.ps1`。脚本先检查已有源码版本，再备份源码、材质资源和图形设置。若发现其他修改会停止，避免覆盖。
2. 运行 `Build-CoastArt.ps1`。它调用 `Deepsea.Editor.CoastMaterialsBuild.Build`，构建已有验收场景，不调用会重建地形的白模构建器。
3. 输出位置为 `Builds/CoastArtV4/GuichaoBay-Art.exe`；旧 v3 与白模播放器保留。
4. 自动检查输出为 `Verification/coast-art-v4/result.json` 与同目录截图。需确认编译、材质、鱼群路径、行船、步行与上下船，并检查 1080p 帧时间。
5. 人工对照 reference、pier-close、cave-water、grey-comparison，重点查看灯室遮挡、窗框贴合、苔藓分布、木材色差与叶片闪烁。通过后才切换桌面入口。

运行参数：`-coast-materials -coast-ecology -screen-fullscreen 0 -screen-width 1920 -screen-height 1080`。

仍保留 v3 的约 1080p 三维渲染像素预算，高分辨率窗口会降低 renderScale。v4 没有实测帧数，不能引用 v3 的约 81 FPS 作为 v4 性能。

# 深海灯塔：近岸生态制作版 v3

沿用已验收 EastCoast-Blockout-3-Natural 的地形、碰撞网格和参考镜头，增加可独立关闭的视觉生态层。本包是现有 Unity 工程的增量源码与实机证据，不是独立完整工程。

复用原工程 CoastSlice 的 island_tree_01 扫描树木、fern_02 扫描蕨类及各自贴图；保留扫描资源的朝向与缩放，有 LODGroup 时选择最低可用网格 LOD，无 LODGroup 且存在预制合并网格时只使用合并网格，避免重复绘制源子节点；，统一使用新生态着色器。复用原 ReefDetails 的扇形珊瑚、块状珊瑚和海绵生成方法，补充合批海草、海带及枝状珊瑚。鱼群为本轮生成的三种外观和体型，不声称是最终写实物种模型。

植被通过材质实例化绘制，水下植物和珊瑚合并为三份网格；没有新增碰撞体。泊位航道和步道有留空，穿洞区域留出缓冲。新鱼群路线在启动时做完整周期包围采样，运行时沿预计算路线游动，尾鳍用着色器摆动。鱼群尚未加入受惊或玩家互动行为。

运行：Builds/CoastEcologyV3/GuichaoBay-Ecology.exe，参数 -coast-materials -coast-ecology。桌面“深海灯塔－材质光照制作版”指向本轮。F2 开关生态，F4 白模对照，F7 洞口，F8 帧率，F9 开关水面；WASD 移动，F 上下船。

原白模、材质首版和水体 v2 播放器保留。F4 会隐藏新增生态并恢复原白模占位鱼，便于同机位对照。本轮继续使用 v2 的跨阶容错参数 0.48 米。

依赖：原 Unity 2022.3.62f3c1 工程、URP 14.0.12、现有 CoastSlice 资源、ReefDetails/ReefLifeGarden 与已验收白模资源。关闭 Unity Editor 后执行 Install-CoastEcologyV3.ps1 安装，再执行 Build-CoastMaterials.ps1 构建及完整实机检查。不要调用旧 CoastBlockoutBuild.Build 重建白模。

新增实例材质在运行时创建，构建器保留实例化着色器变体。首次初始化曾发现海草顶点的非有限值与鱼群索引边界问题，已修正；最终报告及真实运行截图见 evidence。

目前仍为生态首版：分布密度、树冠构图、鱼体精细度及完整水面表现仍需继续打磨，未达到目标图的最终美术效果。性能采样仅代表报告机器、1080p 与固定参考机位；交互版限帧 60。

高分辨率窗口：默认把三维像素预算控制在约 1920×1080。窗口小于该预算时 renderScale=1；窗口扩大时按像素数量自动降低 URP renderScale，最低 0.5。界面仍在窗口分辨率绘制。这是清晰度与帧率的取舍，不代表原生高分辨率性能提升。报告分别记录 benchmarkWindow、benchmarkRenderScale 和 benchmarkRenderResolution。

最终实机检查通过：4 棵树、101 丛蕨类、193 簇海草、89 丛海带、76 组珊瑚、三类外观共 88 条鱼。鱼群完整周期 14080 个包围采样无障碍；新增生态不含碰撞体。步行往返 12/12 航点、原上下船与航行检查通过。334 份已验收文件哈希保持一致。

1080p 固定机位解除限帧采样平均 80.62 FPS，平均 12.40 ms，P95 20.10 ms，P99 24.02 ms；存在较慢帧，不能称为稳定 60 FPS。高分辨率窗口 2854×1729、renderScale 约 0.648、三维渲染约 1850×1121 的复核平均 81.08 FPS，并通过解除限帧的往返与上下船检查。完整数据见报告。生态增加后开销高于水体 v2，仍需继续优化植被渲染。

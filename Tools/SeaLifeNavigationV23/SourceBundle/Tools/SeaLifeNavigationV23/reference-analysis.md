## 操作

W推进；松开滑行；S先制动再倒车；A/D平滑转向。F7切换v22水材质和原推进算法与v23波浪/船控，两种状态共享v23尾迹、视觉层和碰撞轮廓，不等同于完整v22二进制还原。原有上下船、钓鱼和鱼箱操作继续使用。

# 深海灯塔：第三阶段水体细节 v2

在已验收白模与第三阶段材质首版上继续制作。本轮增加双层波纹法线、天空反射的轻微明暗变化、深度交界处的破碎薄泡沫，以及照射到浅海沙底和水下岩面的动态焦散。

焦散为编辑器生成的 512×512 无缝纹理，运行时叠加两次滚动采样；沿深度与表面朝向衰减，并受主光阴影遮挡。它没有增加实时反射相机、逐帧 CPU 像素计算或新的地形。

这仍然是制作中的实机版本。波纹使用着色器法线，未做几何波浪；反射为简化天空色，未实现屏幕空间或平面反射；尚未加入折射、生态植被和多种鱼群，也未达到目标参考图的最终美术效果。

运行文件为原工程 `Builds/CoastMaterialsV2/GuichaoBay-Water.exe`，启动参数 `-coast-materials`。桌面“深海灯塔－材质光照制作版”指向本轮；上一轮 CoastMaterialsV1 和已验收 CoastBlockoutV1 播放器保留。F4 同机位切换白模，F7 洞口，F9 显示／隐藏水面，F8 帧率；WASD 移动，F 上下船。

依赖已有 Unity 2022.3.62f3c1、URP 14.0.12、原项目 CoastSlice 贴图与已验收 CoastBlockout 资源。Files 是增量源码，不是完整工程。关闭 Unity Editor 后执行 Install-CoastWaterV2.ps1 安装，再执行 Build-CoastMaterials.ps1 构建并运行实机验证。构建入口为 Deepsea.Editor.CoastMaterialsBuild.Build；不要调用旧白模几何构建入口。

本轮只修改材质着色器、材质层初始化、材质版构建器及验证代码。原白模场景、模型、碰撞网格与相机未修改。安装前备份相关旧源码。

实机证据与完整验证见 evidence。water-details-off 是在同一版本内关闭新增波纹、泡沫、焦散的对照图；grey-comparison 是同机位白模。water-depth 为诊断图，不是成品画面。性能数值仅代表报告的设备、1080p 与固定参考机位采样，交互版限帧 60。

## 本轮发现并处理的步行问题

首轮实机测试中，角色在第 4 段上坡的台阶转折处发生卡住，返程／登船检查因此失败。解除限帧复测曾通过，但随后 60 FPS 复测再次失败，所以没有把一次通过视为修复。

该转折处相邻梯段有侧缘交叠，进线的轻微变化会让角色碰到高于普通踏步的侧缘。本轮在东岸制作版运行时，将 CharacterController 的跨阶上限从 0.32 米提高至 0.48 米；原控制器源码、接受验收的地形与碰撞网格均未改。参数更改由 CoastMaterialsAppearance 初始化，旧版播放器不受影响。报告记录 characterStepOffset 和局部台阶高度采样。

固定机位性能采样与游玩检查分开：1200 帧性能采样解除限帧，随后航行、步行、上下船按交互版实际的 60 FPS 上限运行。另以 -whitebox-uncapped-navigation 单独复测解除限帧的行走，报告另存 coast-water-v2-uncapped。初次失败与修复前报告保留。最终结果见 evidence。

## 最终验证结果

最终同一播放器在两种模式均通过：60 FPS 游玩模式、解除限帧游玩模式。两次检查均完成 12/12 步行航点、约 42.6 米往返、原上下船操作与约 15.7 米无接触航行；鱼群路径 160 点、鱼体包围 3520 个采样无碰撞。

1920×1080、Intel Arc 130T GPU、固定参考机位 1200 帧解除限帧采样：128.23 FPS，平均 7.80 ms，P95 8.99 ms，P99 9.84 ms；独立复核 127.84 FPS。此前材质首版约 135 FPS，本轮单次采样约增加 0.41 ms，差值包含运行波动，不是严格配对的 GPU 性能测量。交互版仍限帧 60。

334 份已验收资源、场景和旧版文件 SHA-256 一致；上一轮材质播放器也保持原哈希。源包保留修复前失败报告及复核记录。

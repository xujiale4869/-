## 实际内容

- 11 个 Blender FBX、11 份可编辑源文件，合计 {{AUTHOR_TRIANGLES}} 三角。源文件在 `Tools/SeaVillageV31/Masters`，FBX 在 `Assets/Deepsea/Resources/SeaVillageV31/Models`。原包保存在 `Tools/SeaVillageV31/OriginalInputs`。
- 运行时采用同一批 Blender 生成三角的 Y-up 米制 JSON 烘焙 Unity Mesh，保留木墙/屋顶/海石/暖窗/黄铜/绳索材质分区。三座房屋实际使用生成网格，材质与植物沿用已有资源；没有把原稿的方块回退当成最终模型。
- 六类新形态为鳗草、公牛藻、柳珊瑚、管海绵、桌形珊瑚、海葵。实际水下布置 {{FLORA}} 处，其中六种新网格计数依次为 [{{SPECIES}}]，另保留部分旧绿色海带/鹿角珊瑚。潮间带实际 {{SHORE}} 处。这些是本扩展层的布置数，不代表全游戏所有植物总数。
- 植物重新采样可见底面、受限法线倾斜并按变换后的形状控制高度；房屋主体移到较温和的地段，前场增加台阶/栏杆/桩撑；修船台提供连到岸上的水上木通道。院落与既有岸坎的可见承接仍不够清楚，部分角度有树冠遮挡，不能据此宣称建筑落地美术通过。酒馆鱼架复用既有鱼模型，光学道具采用黄铜材质，但目前轮廓尚不足以清晰辨认为望远镜；小径合并为两组静态材质网格。首稿的高石基与树冠遮挡单列为历史失败记录。
- 三座建筑是后续 NPC 使用的场景据点，没有新增 NPC 行为、交易、室内或自动收益。新区域的所有步行路径尚未逐段人工验证，不能据此承诺任意路线连通。

## 重建

`Tools/SeaVillageV31/Rebuild-Village.ps1` 默认核对冻结输入；`-Build` 重建保存的 v31 场景，`-Prepare` 显式重生成/烘焙并从 v30 另存场景，生成新稿需重新验收。普通产品名仍为 v21，v31 布局首次复制 v30 到独立文件 `sea-bay-expansion-v31.json`。

精确旧 v30 源码检出 `9069585`。旧 v30 冻结检查会正确拒绝本次共享源码升级，请勿用旧恢复脚本覆盖新源码。首次最终化流程在普通启动创建 v31 布局前运行；其正常存档前置断言不适合反复使用。
